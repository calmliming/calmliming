全栈开发者。博客在 [calmliming.github.io](https://calmliming.github.io)，记了一些前端和算法的笔记。

### 小东西

[**luna-care**](https://github.com/calmliming/luna-care)　记住她的日子<br>
<sub>记录女朋友的生理期，推算下一次并提前提醒。数据只存在手机里。</sub>

[**purecam-android**](https://github.com/calmliming/purecam-android)　只是拍照<br>
<sub>纯净的安卓相机，取景框里看到的就是拍下来的。滤镜可以细调。</sub>

[**model-bridge**](https://github.com/calmliming/model-bridge)　一座桥，把模型分给朋友<br>
<sub>自托管的 AI API 中转平台。多账号轮询，每人一个 Key，用量都记着。</sub>

[**env-vault**](https://github.com/calmliming/env-vault)　把散落的配置收好<br>
<sub>本地优先的桌面应用，管理各个项目的配置文件和模型凭据。</sub>

[**ai-desk**](https://github.com/calmliming/ai-desk)　一张放得下很多模型的桌子<br>
<sub>多模型 AI 工作台：对话、并排对比、提示词库、和文件对话。</sub>

[**ai-novel**](https://github.com/calmliming/ai-novel)　写小说时，身边有个帮手<br>
<sub>移动端优先的 AI 写作工具。续写、改写、润色，每一版都留着。</sub>

[**ffmpeg-service**](https://github.com/calmliming/ffmpeg-service)　剪辑和转码，交给它<br>
<sub>把常用的 FFmpeg 功能做成 HTTP 接口。</sub>

### 常用

TypeScript、Node.js、Next.js、React、Vue、Electron、Flutter、Kotlin、PostgreSQL、Docker
